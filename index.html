    How this browser lab relates to ROS 2
    ROS2Learn is an educational ROS 2 simulator. Its Python API and CLI reproduce the ROS 2 concepts used in these lessons, but the browser environment is not a complete DDS-based ROS 2 installation.
    Version 0.1 teaches the CLI only; Python comes next. Commands use the common Humble/Jazzy syntax. This lab supports only single publications with --once, and a small JSON/YAML flow-mapping subset. The 2-second velocity hold and speed limits are choices of this simulated controller, not ROS 2 guarantees. /odom and /scan are reserved graph endpoints and do not emit sensor data yet. The temporary CLI publisher exits after publishing; it is not a permanent student node.
