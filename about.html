About

KineCourse is a free and open-source educational environment for learning robotics communication, sensing, perception and coordinate frames in a browser.

KineCourse is an independent educational project for learning concepts and workflows used with ROS™ 2.

ROS is a trademark of Open Source Robotics Foundation, Inc. KineCourse is not affiliated with or endorsed by Open Robotics.

Educational runtime

Python, NumPy and your algorithms are real. The robotics APIs, CLI and sensors are educational implementations for these exercises.

The runtime implements a subset of rclpy, messages, services, parameters, actions, tf2, cv_bridge and cv2. It is not a full robot middleware installation.

No DDS, QoS negotiation, TF history, native OpenCV, Gazebo, RViz, Nav2, SLAM or package builds run here.

Simulation

Camera: 320 × 240 RGB at 8 Hz. LiDAR: 120 rays at 5 Hz. Odometry: ideal 2D pose at 5 Hz. TF uses the latest planar transforms.

Velocity commands expire after two seconds. The simulator limits speed to 2 m/s and 3 rad/s. These are controller policies, not ROS 2 guarantees.

Slow callbacks drop sensor frames. Stop terminates the Python worker, including infinite loops; Python cleanup code may not run. Each browser tab has a separate world.

Assessment and privacy

Checks observe runtime behaviour and accept multiple solutions. They support practice, not secure grading. Public source and browser tools expose lesson data and checkers.

No account, backend or analytics. Preferences are stored in your browser. The first Python run downloads Pyodide and NumPy from jsDelivr.
