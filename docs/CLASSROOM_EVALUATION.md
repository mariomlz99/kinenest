# Classroom evaluation plan

No telemetry or student tracking is implemented.

A future lecturer-led evaluation could compare time to the first successful command, callback/frame misconceptions, exercise completion, student feedback and transfer to a real ROS 2 workspace. Distinguish tool usability from learning gains. Use comparable tasks and document prior programming/robotics experience.

Any formal study involving students needs the applicable university ethics, consent and data-handling process before collecting data. Participation and course assessment should be considered separately. This document is a planning note, not an approved study protocol.
