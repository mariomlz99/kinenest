# Naming candidates — preliminary screen, 2026-10-03

The repository and deployed URLs remain ros2learn until the lecturer chooses a replacement.

Preferred working candidate: **KineCourse — interactive robotics foundations**. Alternative: **KinePractice**. These avoid ROS in the product name and describe motion plus learning. Exact-name web searches did not surface an obvious matching robotics teaching product during this preliminary check; this is not trademark clearance, a domain availability check, or a guarantee of exclusive use.

Rejected early candidates: NodeTrail already names software/a game, and Nodeward already appears as a GitHub organisation. See https://play.google.com/store/apps/details?id=com.prfounder.nodetrail and https://github.com/nodeward.

Before a public rebrand, search similar names and relevant goods/services in TMview/BOIP and agree on the final name. EUIPO explains why absence of an exact match is not sufficient: https://www.euipo.europa.eu/en/trade-marks/before-applying/availability . Apache-2.0 for original code does not establish rights to a product name.
