# ROS reference policy

KineNest currently teaches a **ROS 2 Jazzy-aligned beginner workflow**. Official ROS 2 documentation is the source of truth. Where newer distributions differ, KineNest documents the distinction rather than silently presenting obsolete syntax. KineNest does not claim byte-for-byte or native ROS compatibility.

As checked on 2026-10-05, the [official release list](https://github.com/ros2/ros2_documentation/blob/rolling/source/Releases.rst) lists Lyrical Luth (May 2026, supported to May 2031), Kilted Kaiju (May 2025, to December 2026), Jazzy Jalisco (May 2024, to May 2029), and Humble (to May 2027). Jazzy remains a suitable fixed teaching target, although Lyrical is now the newest stable LTS. Revisit this choice during compatibility maintenance.

Before a ROS-facing feature changes, review the corresponding official Jazzy page and the current stable page. Record the API or command, any material difference, and KineNest's educational boundary in `ROS_JAZZY_MAPPING.md`. Do not copy Rolling-only behavior into Jazzy lessons. The public docs site returned an access challenge from this environment, so review used the official `ros2/ros2_documentation` Jazzy and Lyrical source branches, with public docs links retained for students.

Key references: [Jazzy tutorials](https://docs.ros.org/en/jazzy/Tutorials.html), [Jazzy package tutorial source](https://github.com/ros2/ros2_documentation/blob/jazzy/source/Tutorials/Beginner-Client-Libraries/Creating-Your-First-ROS2-Package.rst), [Jazzy Python pub/sub source](https://github.com/ros2/ros2_documentation/blob/jazzy/source/Tutorials/Beginner-Client-Libraries/Writing-A-Simple-Py-Publisher-And-Subscriber.rst), [Jazzy C++ pub/sub source](https://github.com/ros2/ros2_documentation/blob/jazzy/source/Tutorials/Beginner-Client-Libraries/Writing-A-Simple-Cpp-Publisher-And-Subscriber.rst), [Jazzy launch source](https://github.com/ros2/ros2_documentation/blob/jazzy/source/Tutorials/Intermediate/Launch/Creating-Launch-Files.rst).
