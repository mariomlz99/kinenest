# CMake subset

The parser understands only `cmake_minimum_required`, `project`, `find_package(... REQUIRED)`, `add_executable`, `ament_target_dependencies`, `install(TARGETS ... DESTINATION lib/${PROJECT_NAME})`, `install(DIRECTORY launch DESTINATION share/${PROJECT_NAME})` and `ament_package`. One source file per executable is supported. It checks named sources, dependencies and install declarations before passing each source to the real browser compiler. Unsupported declarations fail explicitly; KineNest does not run CMake.

The [official Jazzy C++ pub/sub tutorial](https://github.com/ros2/ros2_documentation/blob/jazzy/source/Tutorials/Beginner-Client-Libraries/Writing-A-Simple-Cpp-Publisher-And-Subscriber.rst) uses `find_package`, `add_executable`, `ament_target_dependencies` and `install(TARGETS ... DESTINATION lib/${PROJECT_NAME})`. The newer [Lyrical C++ tutorial](https://github.com/ros2/ros2_documentation/blob/lyrical/source/ROS-Framework/client-libraries/Working-with-Client-Libraries/Writing-A-Simple-Cpp-Publisher-And-Subscriber.rst) still shows this beginner shape. Full CMake control flow, generator expressions, libraries and transitive dependencies are outside this lesson.
