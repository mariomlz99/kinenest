# Jazzy concept mapping

Target: ROS 2 Jazzy. Checked against the official Jazzy documentation source and the current Lyrical documentation source on 2026-10-05. Fidelity describes the teaching concept, never native or byte-compatible execution.

| Official ROS 2 concept | Official Jazzy source | KineNest implementation | Fidelity | Known difference | Newer distro difference | Native transition |
|---|---|---|---|---|---|---|
| Workspace `src`, build/install/log | [Workspace](https://github.com/ros2/ros2_documentation/blob/jazzy/source/Tutorials/Beginner-Client-Libraries/Creating-A-Workspace/Creating-A-Workspace.rst) | Bounded `WorkspaceModel` | Conceptual | In-memory tree | Lyrical reorganizes docs, retains workflow | Create `~/ros2_ws/src` on Linux |
| Python/C++ package | [Package](https://github.com/ros2/ros2_documentation/blob/jazzy/source/Tutorials/Beginner-Client-Libraries/Creating-Your-First-ROS2-Package.rst) | Generated ament-shaped files | Structural subset | No native ament | Lyrical beginner structure remains comparable | `ros2 pkg create` |
| `package.xml` dependencies | [Package](https://github.com/ros2/ros2_documentation/blob/jazzy/source/Tutorials/Beginner-Client-Libraries/Creating-Your-First-ROS2-Package.rst) | Bounded structural parser | Subset | No full manifest validation/rosdep | No material beginner change found | Declare/install real dependencies |
| Python entry points | [Python pub/sub](https://github.com/ros2/ros2_documentation/blob/jazzy/source/Tutorials/Beginner-Client-Libraries/Writing-A-Simple-Py-Publisher-And-Subscriber.rst) | Literal console scripts, real CPython import | High for entry lookup | Pyodide and shim | Lyrical retains console script pattern | Test with native `ros2 run` |
| C++ target/install | [C++ pub/sub](https://github.com/ros2/ros2_documentation/blob/jazzy/source/Tutorials/Beginner-Client-Libraries/Writing-A-Simple-Cpp-Publisher-And-Subscriber.rst) | CMake subset, real browser Clang | Structural subset | No native CMake/ament | Lyrical retains beginner declarations | Build with native colcon |
| `colcon build` | [Package](https://github.com/ros2/ros2_documentation/blob/jazzy/source/Tutorials/Beginner-Client-Libraries/Creating-Your-First-ROS2-Package.rst) | Checks files and compiles language code, records install | Workflow | Not colcon | No material beginner change found | Run native colcon |
| `source install/local_setup.bash` | [Package](https://github.com/ros2/ros2_documentation/blob/jazzy/source/Tutorials/Beginner-Client-Libraries/Creating-Your-First-ROS2-Package.rst) | Per-terminal discoverability | Conceptual | No Bash environment variables | Lyrical still teaches local setup | Source base ROS and workspace |
| `ros2 run` | [Package](https://github.com/ros2/ros2_documentation/blob/jazzy/source/Tutorials/Beginner-Client-Libraries/Creating-Your-First-ROS2-Package.rst) | Installed executable starts a worker | Behavioral subset | Browser worker, shim graph | Same CLI form | Run native executable |
| Python `LaunchDescription`, `Node`, `ros2 launch` | [Launch](https://github.com/ros2/ros2_documentation/blob/jazzy/source/Tutorials/Intermediate/Launch/Creating-Launch-Files.rst) | Literal parser and process group | Subset | No arbitrary Python, substitutions or events | Lyrical reorganizes docs; same basic Node concept | Use full native launch |
| Node names, parameters, remapping | [Launch formats](https://github.com/ros2/ros2_documentation/blob/jazzy/source/How-To-Guides/Launch-file-different-formats.rst) | Applied to actual browser graph and shim parameters | Behavioral subset | Scalar parameters/topics only | No material basic change found | Observe native graph/CLI |

Newer Lyrical sources: [package](https://github.com/ros2/ros2_documentation/blob/lyrical/source/ROS-Framework/client-libraries/Working-with-Client-Libraries/Creating-Your-First-ROS2-Package.rst), [C++ pub/sub](https://github.com/ros2/ros2_documentation/blob/lyrical/source/ROS-Framework/client-libraries/Working-with-Client-Libraries/Writing-A-Simple-Cpp-Publisher-And-Subscriber.rst), [launch](https://github.com/ros2/ros2_documentation/blob/lyrical/source/Developer-Tools/Launch/Creating-Launch-Files.rst). Lyrical is newer and supported longer than Jazzy; the basic taught forms above remain suitable for Jazzy.
