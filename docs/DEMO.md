# Demonstration outline

A proposed 30–45 second manual recording, after release validation:

1. Open KineCourse and show the six-session navigation (3 s).
2. Session 1: ros2 topic list, then a Twist moves the robot (5 s).
3. Session 2: run a subscriber and show LiDAR-driven avoidance (6 s).
4. Session 3: show real NumPy red-pixel detection and camera centering (7 s).
5. Session 5: move and turn; base_link and laser_link follow while target stays fixed. Show the inspector (10 s).
6. Session 6: briefly show the beacon challenge and passing checks (6 s).

Use legible editor text and a 1440-pixel viewport. Keep commands English. No competitor claims, logos or decorative emoji. No automatic recording is implemented. A Python/TF screenshot can later become a social card; PRODUCT.socialImage is unset until an image and final public URL are selected.
