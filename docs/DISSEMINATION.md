# Demonstrating KineNest

KineNest is an independent open educational project by Mario Malizia. It lets students work with robotics interfaces and sensors before spending time on installations and workspace setup. Real Python and NumPy run in the browser; a small experimental C++ path compiles to WebAssembly. The robotics middleware APIs and world are educational implementations.

A 30–45 second demonstration:

1. Open Session 1 and list topics in the learning terminal.
2. Publish Twist and show robot motion.
3. Run a Session 2 scan callback and obstacle controller.
4. Show Session 3 camera pixels and centroid control.
5. Move Session 5 base_link and sensor axes; compare the inspector with a transform query.
6. End at the real-environment transition page.
